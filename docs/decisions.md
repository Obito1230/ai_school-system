## D1 技术栈选型：Python 后端 + 原生前端（2026-11-15 确认）

**决策**：后端 Python (FastAPI + SQLite)，前端三端均为原生 HTML/CSS/JS 单文件 SPA（零第三方依赖、零构建）。

**依据**：
1. 计划文档第 158 行明确「负责人具备 Python、前端、数据库能力；**后端以 Python 为主**」；
2. 计划文档第 15 行：申请书未明确前端框架，交由 T1.5 选型确定——本决策即 T1.5 前端框架选型的 Demo 阶段结论；
3. 全文检索计划文档，「Java / Spring / Vue」零命中，不存在「主要用 Java+Vue 开发」的要求；
4. 负责人确认维持该选型（2026-11-15 会话确认），不迁移 Java/Vue。

**影响范围**：无迁移成本。若后续 P3 阶段团队要求 Vue 工程，前端三页可平迁（接口层已统一 Bearer + RESTful）；后端如需 Java 化需重写五服务，成本高，需另行立项评审。

**Demo 现状**：backend/（FastAPI 五服务）+ web/admin|student|elder/index.html，接口契约见 docs/接口文档.md。
