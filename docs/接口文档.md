## 通用约定

- 编码：UTF-8，请求/响应均为 JSON（`Content-Type: application/json`）。
- 鉴权：`Authorization: Bearer <token>`，token 由登录接口返回（JWT，12 小时有效）。
- 角色权限：`admin`（管理员）可访问全部接口；`student`/`senior` 仅可访问业务接口；管理类接口未登录返回 `401`，非管理员返回 `403`。
- 统一错误格式：`{"detail": "错误说明"}`；参数校验错误为 FastAPI 标准格式 `{"detail": [{loc, msg, type}]}`。

## 2. 用户服务（user）

### POST /api/v1/users — 注册
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 用户名（唯一） |
| password | string | 是 | 密码 |
| real_name | string | 否 | 姓名 |
| role | string | 否 | student（默认）/ senior / admin |
| tenant_id | string | 否 | 租户（学院/校区），默认 default |

响应：`{"id": 1, "username": "stu01", "role": "student", "tenant_id": "信息学院"}`

请求：`{"username": "admin", "password": "admin123"}`
响应：
```json
{"token": "eyJhbGciOi...", "user": {"id": 1, "username": "admin", "real_name": "系统管理员",
 "role": "admin", "tenant_id": "default", "credit_score": 100}}
```

错误：`401 用户名或密码错误`

### GET /api/v1/users/me — 当前用户信息（需登录）
响应：同上 `user` 对象。

### GET /api/v1/admin/users — 用户列表（需管理员）

响应：`{"total": 3, "items": [{...用户对象}]}`

## 3. 工单服务（order）

### 状态机（T2.5）
```
created → ai_reviewing → {published | pending_manual_review | blocked}
pending_manual_review → {published | blocked}
published → matching → accepted → in_progress → completed → evaluated
任意中间态（除 blocked/evaluated/cancelled）→ cancelled
blocked 为终态：L3 硬拦截，代码级不可自动发布（安全硬约束）
```
非法迁移返回 `400 非法状态迁移: X → Y`。

### POST /api/v1/orders — 创建工单（需登录）
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| text | string | 否 | 口语化求助文本（Demo：直接走规则解析；无 text 时使用内置示例） |
| transcript | string | 否 | 已有转写文本（前端 ASR 结果回传时使用，优先于 text） |
| asr_confidence | float | 否 | 转写置信度（transcript 存在时默认 0.9） |
| title / task_type / urgency / location / time_slot / description | string | 否 | 手工指定槽位（不填则由 AI 解析） |
| tenant_id | string | 否 | 租户 |

**处理流程**：转写 → 语义解析（槽位填充）→ 风险分级（管理员规则表）→ 状态推进：
- L1 且 auto_publish → `published`（自动发布进任务广场）
- L2 或低置信度 → `pending_manual_review`（进入人工复核队列）
- L3 → `blocked`（硬拦截 + 官方渠道指引 + 拦截日志）

响应：`{"order": {工单对象}, "blocked": true|false}`
工单对象字段（对应计划 6.1 work_order）：
```json
{"id": 1, "work_order_no": "WO20261030183000001", "tenant_id": "default", "requester_id": 2,
 "title": "...", "transcript": "...", "asr_confidence": 0.92, "task_type": "学业答疑",
 "urgency": "普通", "location": "图书馆", "time_slot": "明天", "description": "...",
 "parse_confidence": 0.9, "risk_level": "L1", "risk_confidence": 0.92, "status": "published",
 "is_official": false, "blocked_reason": "", "official_channel_ref": "",
 "volunteer_id": null, "rating": null, "created_at": "2026-10-30T18:30:00"}
```

### GET /api/v1/orders — 任务广场（需登录）
只返回 `published`/`matching` 状态的工单（含官方任务，R18 统一展示）。
**默认排除当前登录用户自己发布的工单**（自己的单不能自己接，去「我的」页查看；管理员查看全量）。
Query：`status`、`keyword`（标题/描述/地点模糊）、`page`、`size`。
响应：`{"total": 2, "items": [...工单对象，含 requester_name 发布者姓名]}`

### GET /api/v1/orders/mine — 我的工单（需登录，v0.3 新增）
返回当前用户相关的全部工单（requester_id 或 volunteer_id 为本人），按 id 倒序。
响应：`{"total": 2, "items": [...工单对象]}`
学生端「我的」页数据源（前端按 requester_id / volunteer_id 分成「我发布的 / 我承接的」两个 Tab）。

### GET /api/v1/orders/{id} — 工单详情（需登录）
直接返回单个工单对象（无 `{order: ...}` 包裹），字段同上；`rating` 已评价时为
`{"score": 5, "comment": "...", "rated_by": "...", "time": "..."}`，未评价为 `null`；
`review_record` 为复核记录数组（人工复核时写入，学生端详情页展示）。

### POST /api/v1/orders/{id}/confirm — 发布前核对/修改（需登录，本人或管理员）
Body（均可选，只传要改的字段）：`{"title", "task_type", "urgency", "location", "time_slot", "description"}`
修改后状态回到 `ai_reviewing` 重新分级（R6：发布前可核对可修改）。

### POST /api/v1/orders/{id}/accept — 接单（需登录）
约束：工单须为 `published`；不能接自己的单。响应更新后的工单（status=accepted）。

### POST /api/v1/orders/{id}/complete — 完成确认（需登录）
Body 可选：`{"proof": "完成凭证说明"}`。状态：accepted → completed。

### POST /api/v1/orders/{id}/rate — 评价（需登录）
Body：`{"score": 1-5, "comment": "评价内容"}`。状态：completed → evaluated。

## 4. AI 算法服务（ai）

> 接入状态（v0.4.3）：`/ai/parse` 已接**智谱 GLM**（OpenAI 兼容端点 `https://open.bigmodel.cn/api/paas/v4/`），
> Key 未配置 / 超时（10s）/ 返回不合法时自动降级本地规则解析（R16 熔断降级），接口形状不变，前端无需改动。
> `/ai/asr` 语音识别仍为 Demo 模拟（GLM 主推文本模型，真实 ASR 需另配讯飞/阿里等服务，配置位已预留 `AIC_ASR_*`）。
> `/ai/risk` 保持管理员规则表驱动（拦截要求确定性，R14）。

### POST /api/v1/ai/ask — RAG 知识库问答（需登录，v0.5 新增）
请求：`{"question": "校园卡丢了怎么办？"}`
响应：
```json
{"answer": "...", "mode": "rag_llm 或 rag_only（无Key纯检索兜底）",
 "sources": [{"id": 1, "title": "校园卡服务指南"}],
 "injected": false, "sensitive_blocked": false}
```
召回：`backend/services/kb.py` 8 篇校园语料 TF 余弦 Top-3；`sources` 可溯源。

### POST /api/v1/ai/ask/stream — RAG 问答流式（SSE，需登录，v0.5 新增）
请求同 /ai/ask；响应 `text/event-stream`：`sources` → `delta`（逐句）→ `done`。

### GET /api/v1/ai/tools/list — 工具注册表（需登录，v0.5 新增）
返回 MCP 风格工具 schema：`search_orders` / `get_credit` / `search_kb`。

### POST /api/v1/ai/tools/call — 工具调用（需登录，v0.5 新增）
请求：`{"question": "stu01 现在多少信用分？"}`
LLM 路由到白名单工具执行（防幻觉工具名）；无 Key 时规则路由兜底。

### 智谱 GLM 配置（环境变量，Key 不进代码/git）
| 变量 | 说明 | 默认 |
|---|---|---|
| `AIC_GLM_API_KEY` | 智谱 API Key（bigmodel.cn 申请）；不设则纯 Demo 规则 | 空（Demo） |
| `AIC_GLM_BASE_URL` | 智谱 OpenAI 兼容端点 | `https://open.bigmodel.cn/api/paas/v4/` |
| `AIC_GLM_MODEL` | 模型名 | `glm-4-flash`（免费，可换 glm-4-plus 等） |
| `AIC_GLM_TIMEOUT` | 单次调用超时秒数 | 10 |

### POST /api/v1/ai/asr — 语音转写（需登录）
请求：`{"text": "可选文本", "audio_b64": "音频base64（学生端 MediaRecorder 录音上传，Demo 阶段不真实识别，仅记录音频大小）"}`
响应：
```json
{"transcript": "...", "confidence": 0.87, "manual_fallback": false,
 "note": "置信度低于阈值时出现，建议二次校验或人工兜底（R5）"}
```
`confidence < 0.80` 时 `manual_fallback=true`。

### POST /api/v1/ai/parse — 意图解析（需登录）
请求：`{"text": "我想请人明天下午在图书馆答疑辅导高数"}`
响应（槽位 + 置信度，R6/R7）：
```json
{"task_type": "学业答疑", "urgency": "普通", "location": "图书馆",
 "time_slot": "明天", "description": "...", "confidence": 0.9}
```

### POST /api/v1/ai/risk — 风险分级（需登录）
请求：`{"task_type": "搬运协助", "urgency": "特急", "scope": "校内"}`
响应：`{"level": "L3", "confidence": 0.92}`
分级逻辑：管理员规则表优先（`backend/services/admin.py` 维护，规则变更即时生效）；无命中时兜底：特急→L2，其余→L1。

### POST /api/v1/ai/vision — 拍照报修多模态识别（需登录，v0.5.1 新增）
请求：`{"image_b64": "图片base64（学生端 canvas 压缩后上传，最长边 800px）", "note": "可选附言"}`
响应（视觉识别 → JSON 槽位，与 /ai/parse 同形状）：
```json
{"task_type": "设备维修", "urgency": "普通", "location": "",
 "time_slot": "", "description": "照片中的故障描述...", "confidence": 0.85}
```
- 模型：GLM-4V-Flash（环境变量 `AIC_GLM_VL_MODEL`），识别失败/无 Key 时降级：有 `note` 走规则解析，无则返回空槽位
- 枚举校验防幻觉：`task_type` 必须在合法枚举内，非法值丢弃降级

## 5. 积分服务（credit）

### GET /api/v1/credits/{user_id} — 查询信用分（需登录）
响应：`{"user_id": 2, "credit_score": 100}`

### GET /api/v1/credits/{user_id}/ledger — 积分流水（需登录）
Query：`page`、`size`。
响应项：`{id, order_id, event, rule_id, rule_version, delta, remark, operator, created_at}`

### POST /api/v1/credits/appeal — 积分申诉登记（需登录）
请求：`{"ledger_id": 1, "reason": "申诉理由"}`（R15 可申诉；Demo 阶段写审计日志留痕，管理员处理流程 P3 完善）

### 积分自动落账（v0.4.2，R15 闭环最小实现）
工单流转时自动写流水并更新信用分（规则取 `credit_rule` 表中 enabled 且 event 匹配的记录留痕 rule_id/rule_version）：

| 触发点 | 对象 | event | delta |
|---|---|---|---|
| 接单 accept | 承接者 | accept | +1 |
| 完成 complete | 承接者 | complete | +5 |
| 评价 rate | 发布者 | rate | +2（守约发布） |
| 评价 rate | 承接者 | rate | ≥3 星 +1×score；<3 星 -2（差评） |

> 失信扣分（breach_penalty -10）、求助频次校验、异常行为惩戒为 P3 T3.3 范围。

## 6. 运营管理服务（admin，全部需管理员）

### 风险规则配置（R11：规则即配置，改动即时生效且留痕）
- **GET /api/v1/admin/risk-rules** — 规则列表
- **POST /api/v1/admin/risk-rules** — 新增
  Body：`{"dimension": "task_type", "condition": "task_type=='代办跑腿'", "level": "L2", "action": "warn_manual_review", "official_channel_ref": "", "adjust_reason": "调整依据"}`
  - `condition` 为 Python 表达式，可用变量：`task_type` / `urgency` / `scope`
  - `action`：`auto_publish`（自动发布）/ `warn_manual_review`（转人工复核）/ `block_and_guide`（L3 拦截并引导官方渠道）
  - 错误：`400 level 必须是 L1/L2/L3`
- **PUT /api/v1/admin/risk-rules/{id}** — 修改（version 自增，写审计日志）
- **DELETE /api/v1/admin/risk-rules/{id}** — 删除（写审计日志）

### 人工复核队列（R12）
- **GET /api/v1/admin/review-queue** — 待复核工单列表（status=pending_manual_review）
- **POST /api/v1/admin/review-queue/{id}/decide** — 复核决定
  Body：`{"decision": "approve|reject|reclassify", "new_level": "L1", "opinion": "复核意见"}`
  - approve → 发布；reject → 拦截；reclassify → 改判等级（改判 L3 则拦截）
  - 复核意见与改判前后等级均写入 `review_record` 留痕
  - 错误：`400 工单状态为 X，不在待复核队列`

### 官方志愿任务（R18）
- **POST /api/v1/admin/official-tasks** — 发布官方任务
  Body：`{"title": "校运会会务志愿者", "task_type": "讲座会务", "description": "...", "location": "田径场", "time_slot": "周六 14:00-17:00", "tenant_id": "default"}`
  官方任务 risk_level=L1、status=published、is_official=true，与学生个人工单同一任务广场展示。
- **GET /api/v1/admin/official-tasks** — 官方任务列表（v0.2 新增）

### 订单管理（v0.2 新增，全部需管理员）
- **GET /api/v1/admin/orders** — 全量工单查询（含待复核/拦截/已取消，区别于任务广场）
  Query：`status`、`risk_level`（L1/L2/L3）、`keyword`（标题/描述/地点/工单号）、`is_official`（true/false）、`page`、`size`
  响应项为工单对象 + `requester`（发布人用户名）、`blocked_by`、`review_record`、`completion_proof` 等
- **GET /api/v1/admin/orders/{id}** — 工单详情（含复核记录/评价/拦截信息）
- **POST /api/v1/admin/orders/{id}/cancel** — 管理员强制取消
  Body：`{"reason": "取消原因"}`（留痕，写入审计日志）；终态（blocked/evaluated/cancelled）不可取消，返回 400

### 用户管理（v0.2 新增，全部需管理员）
- **POST /api/v1/admin/users** — 新建账号
  Body：`{"username", "password", "real_name", "role": "student|senior|admin", "tenant_id"}`
  错误：`400 用户名已存在` / `400 role 必须是 student/senior/admin`
- **PUT /api/v1/admin/users/{id}** — 编辑账号
  Body（均可选）：`{"real_name", "role", "is_active", "tenant_id", "credit_delta": -5, "credit_reason": "调整依据"}`
  `credit_delta` 非空时调整信用分并写入积分流水（event=admin_adjust，可追溯）

### 积分规则
- **GET /api/v1/admin/credit-rules** — 积分规则列表
- **POST /api/v1/admin/credit-rules** — 新增：`{"rule_code": "xxx", "event": "publish|accept|complete|rate", "condition": "守约", "delta": 2, "enabled": true}`
- **PUT /api/v1/admin/credit-rules/{id}** — 修改（version 自增留痕）
- **DELETE /api/v1/admin/credit-rules/{id}** — 删除（v0.2 新增，写审计日志）

### 积分流水总览（v0.2 新增）
- **GET /api/v1/admin/credit-ledger** — 全平台积分流水
  Query：`user_id`（可选筛选）、`page`、`size`
  响应项：`{id, user_id, user, order_id, event, delta, remark, operator, created_at}`

### 看板与审计
- **GET /api/v1/admin/dashboard** — 运营看板
  响应：`{total_users, total_orders, today_orders, orders_by_status, orders_by_risk_level, pending_review, blocked, official_tasks, credit_flows, trend_7d: {"2026-10-24": {created, blocked}, ...近7天}, generated_at}`
  （v0.2 新增 today_orders / official_tasks / trend_7d 近7日趋势）
- **GET /api/v1/admin/audit-logs** — 审计日志（Query：`action` 可筛选如 `l3_block` / `manual_review` / `risk_rule_update` / `login`，`page`、`size`）
  响应项：`{id, action, target, detail, operator, created_at}`
