# 演示视频录制指南（5–8 分钟 · 1080p · MP4）

> 大赛要求：MP4、分辨率不低于 1080p、普通话讲解（可配字幕）、包含项目介绍 + 核心功能演示 + AI 技术亮点。
> 本指南给出**分镜脚本 + 录制 + 剪辑 + 导出**全流程，照着做即可。

---

## 一、准备工作（录之前 10 分钟）

1. 启动服务（Windows PowerShell，项目根目录）：
   ```powershell
   cd D:\project_create\ai_school-system
   .\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
   ```
2. 建议设置真实 GLM Key 环境变量后重启，让 AI 解析/问答走真实大模型（更有说服力）；没 Key 也能录，讲解里说明"规则引擎降级"即可。
3. 演示账号：`stu01 / 123456`（学生）、`admin / admin123`（管理员，以 README 为准）。
4. 提前在学生端发布 1–2 条正常工单、1 条会触发 L3 拦截的工单（如「宿舍空调坏了找人维修搬运」），避免现场输入出错。
5. 浏览器开 3 个窗口分别登录：学生端（http://127.0.0.1:8000/app/）、管理端（http://127.0.0.1:8000/admin/）、适老端（http://127.0.0.1:8000/elder/），先缩小。

## 二、录制工具（三选一）

| 工具 | 适用 | 要点 |
| --- | --- | --- |
| **OBS Studio**（免费，推荐） | 全功能 | 来源加「显示器采集」，设置→输出→分辨率 1920×1080、码率 8000–12000 Kbps |
| **Win + G**（Xbox Game Bar） | 免安装 | Win+G 打开，录应用窗口即可，画质默认够 1080p |
| **QQ/微信录屏** | 最简单 | 注意关闭水印，确认输出分辨率 |

**录音**：耳机麦即可。OBS 在「音频混合器」里只保留麦克风，桌面音频按需。开头先录 5 秒静音试音，确认波形在动。

## 三、分镜脚本（总时长约 6 分钟）

| # | 时间 | 画面 | 讲解词要点 |
| --- | --- | --- | --- |
| 1 | 0:00–0:40 | 管理端登录页→首页 | 「大家好，我们是 XX 团队，作品是校园互助平台——面向高校学生的 AI 互助系统。管理端可以看到用户/工单/风控全貌，AI 能自动解析求助并给出风险等级。」 |
| 2 | 0:40–1:40 | 学生端发布求助：输入「帮我明天上午在图书馆辅导高数」→ 点智能解析 | 「学生用一句话描述需求，大模型自动解析出任务类型、地点、时间、紧急程度，全部字段可人工核对修改后发布。」 |
| 3 | 1:40–2:40 | 发布一条触发拦截的内容（如现金交易类）→ 官方渠道指引弹窗 | 「AI 安全：规则+大模型双重风控。L3 高风险工单直接拦截并引导官方渠道；同时有提示词注入清洗、敏感内容输出过滤。」 |
| 4 | 2:40–3:40 | 学生端 AI 助手页：问「校园卡丢了怎么补办？」→ 展示流式输出+来源徽标 | 「RAG 检索增强：回答基于校园知识库检索结果生成，并标注来源，可解释、不编造。流式输出+思考状态提升交互体验。」 |
| 5 | 3:40–4:30 | AI 助手问「stu01 的信用分多少」→ 工具调用返回 | 「Function Calling：大模型理解意图后调用平台工具（查工单/查信用/查知识库），工具白名单执行，防幻觉。」 |
| 6 | 4:30–5:30 | 双窗口：stu01 发布 → stu02 接单 → 完成 → 互相评价 → 信用分变化 | 「完整互助闭环：接单/完成/评价，信用积分自动落账、每笔流水可追溯可申诉（R15）。」 |
| 7 | 5:30–6:00 | 适老端 15 秒 + 管理端复核 15 秒 + 收尾 | 「适老化端满足工信部适老规范：大图标、高对比度、语音优先。技术栈 Python FastAPI + 原生前端，零外部依赖、一键启动。谢谢观看！」 |

> 录制小技巧：每个镜头开始前把页面刷新到干净状态；报错直接剪掉重录该镜头；鼠标移动放慢。

## 四、剪辑与导出

- 剪辑软件：剪映（免费）或 OBS 直接裁头去尾。
- 必要处理：剪切失误段、给关键步骤加字幕（普通话讲解要求可配字幕）、开头加作品名标题。
- 导出参数：**MP4（H.264）+ AAC 音频、1920×1080、30fps、码率 ≥ 8000 Kbps**，控制在 5–8 分钟。
- 文件命名：`校园互助平台-演示视频.mp4`。
